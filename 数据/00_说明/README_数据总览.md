# 数据文件夹总览

本目录汇集 2027 年 MCM/ICM C 题（*On Time, On Paper*）所需的全部公开数据，采集时间 **2026-11-24**（东八区）。
目标是能把"已到达、延误、取消、改道、字段缺失"五类结果分开建模，并用气象条件解释与预测。

**规模：296 个文件，2.75 GB，核心航班记录 26,227,577 条航段（2023-01-01 → 2026-09-30）。**

```
数据/
├── 00_说明/                  总览、字段字典、机场选择说明、采集脚本、文件清单
├── 01_航班运行_BTS_OTP/      ★核心：BTS 航班准点性能（45 个月）
│   ├── 原始压缩包/           45 个官方月度 zip（未改动，CRC 全部通过）
│   └── 整理数据/             45 个航班级子集(csv.gz) + 全美机场日度汇总
├── 02_天气_气象/             IEM 逐小时 METAR、NCEI LCD 逐小时、GHCN 逐日、HURDAT2 飓风
├── 03_机场航线_元数据/       机场/跑道/导航台/时区/航空公司/航线 + 派生查找表
├── 04_运力与需求/            TSA 每日安检人数（需求侧）
└── 99_质量检查/              下载日志、清单、审计表、完整性校验报告
```

> **未纳入票价数据**：BTS 的逐票（DB1B）与单张票价不在公开的月度航段表中，题目也明确"没有提供票价"。
> 若后续需要，应从 BTS *Airline Origin and Destination Survey* 单独获取（需另行申请下载接口），
> 或按 `Distance`、舱位与承运人类型做显式假设（属推断量，须与观测数据分开报告）。

## 数据能回答的问题

| 题目要求 | 对应数据 |
|---|---|
| 让"消失的航班"计入 | `Cancelled` / `Diverted` / `DivReachedDest` / `ArrTime` 缺失标记，**取消航班在册但无到达时间** |
| 看清排名背后的东西 | 逐航班的承运人、时刻段（`DepTimeBlk`）、距离、机型尾号；机场日度汇总可按月/季/时段重组 |
| 中断前预测 | 全量航班级特征 + 同一时刻机场 METAR + 前序航班状态（`Tail_Number`） |
| 困难的日子 | TSA 日客流峰值、HURDAT2 飓风、GHCN 暴雪、LCD/METAR 低能见度 |
| 评分卡 | 机场日度指标已可直接聚合成月/季口径 |

## 关键事实（由数据实测，见 `99_质量检查/校验报告.md`）

| 指标 | 全期均值 | 月度最小 | 月度最大 |
|---|---|---|---|
| 月度航段数 | 58.3 万 | 50.3 万（2023-02） | 63.5 万（2024-07） |
| 取消率 | **1.513%** | 0.145%（2023-11） | **4.712%**（2026-01） |
| 改道率 | 0.268% | 0.097% | 0.538% |
| 到达时间缺失率 | 1.542% | 0.154% | 4.750% |
| 到达延误 ≥15 分钟占比 | **21.194%** | 13.053% | 28.658% |
| 填写了延误原因代码的占比 | 11.532% | 7.443% | 16.712% |

- 全期 **395,923 班取消**、**71,061 班改道**、**403,353 条记录没有到达时间**。
- 取消率与"缺到达时间率"几乎重合（1.51% vs 1.54%）——说明**缺失本身就是结果**，不是随机噪声。
- 只有 11.5% 的航班带有延误原因分解，而 21.2% 的航班晚点 ≥15 分钟 → 原因字段**远不足以**解释延误。
- 在 20 座机场中，取消率跨度达 **4.8 倍**：SLC 0.65% ↔ LGA 3.14%；平均到达延误从 SLC 11.9 分钟到 DFW 22.0 分钟。
- 全表仅 **1 条**重复主键（日期+承运人+航班号+起点+计划时刻）——数据质量足以支撑航班级建模。

## 数据构成

### 1. 航班运行（BTS）

| 项目 | 内容 |
|---|---|
| 来源 | U.S. DOT / BTS, *Airline On-Time Performance*（TranStats PREZIP） |
| 覆盖 | 2023-01 – 2026-09（45 个月）；2026-10 及以后尚未发布 |
| 单元 | 一次"报告承运人 × 航班号 × 日期"的**航段**（origin→dest 的计划飞行） |
| 字段 | 每月 110 列，含计划/实际时刻、滑行、改道链路、延误原因分解 |
| 整理后 | 航班级子集保留 45 个核心字段，仅保留涉及 20 座采样机场的航班（约 78%） |

### 2. 气象（三套互相独立可校验）

| 数据集 | 内容 | 覆盖 | 文件数 |
|---|---|---|---|
| `METAR_IEM/` | 逐小时 METAR（°F，UTC）：风、能见度、云底、天气代码 | 20 机场 × 2023–2026.09 | 80 |
| `LCD_逐小时/` | NCEI LCD 原始归档（°C，本地时）：125 列，含 SPECI 与日/月汇总 | 19 机场 × 2023–2025 | 57 |
| `GHCN_Daily/` | GHCN-Daily 逐日：降水/降雪/雪深/最高最低温/风速 | 20 机场，含 1940s 起历史 | 20 |
| `飓风HURDAT2/` | 大西洋 1851–2025、东北太平洋 1949–2025 最佳路径 | 6 小时 | 3 |

> **已知空缺**（不影响主线）：NCEI LCD 尚未发布 2026 年目录，且 **DEN 不在 LCD 站点之列**；
> 这两处由 IEM METAR 补齐（DEN 2023–2026、其余机场 2026 年均有逐小时数据）。

### 3. 机场与航线元数据

- `ourairports_*.csv`：机场（IATA/ICAO、经纬度、类型、海拔）、跑道、导航台、国家/地区、频率。
- `openflights_*.dat`：机场**时区**（BTS 时间均为本地时间，跨机场比较必须换算）、航空公司名录、航线对。
- `查找表_机场_含流量.csv`：370 座机场的坐标、时区、跑道数、以及本数据算出的到达量/取消率/平均延误/排名 —— **开箱即用**。
- `查找表_承运人.csv`：报告承运人代码 ↔ 名称/ICAO/呼号/国家。
- `机场_ISD气象站映射.csv`：机场 ↔ NOAA 站号，含匹配距离（全部 ≤ 3.3 km）。

### 4. 需求侧

`TSA_每日安检人数_2023_2026.csv`：全美每日通过安检人数，1422 天（2023-01-01 – 2026-11-22），
用于刻画节假日峰值、夏季高峰与需求异常——题目第 4 问"旺盛出行需求"的直接协变量。

```powershell
cd 数据\00_说明\脚本

python 下载_LCD.py                     # NCEI LCD 逐小时（2023–2025）
python 下载_GHCN.py                    # GHCN-Daily 逐日
python 下载_TSA.py                     # TSA 每日客流
python 整理_航班数据.py                # 航班级子集 + 机场日度汇总 + 审计表

python 生成_文件清单.py                # 全量文件的 SHA256 与来源 URL
```

## 口径与数据缺陷（写作时必须交代）

1. **取消 ≠ 0 延误**：取消与改道航班的 `ArrDelay`/`ArrTime` 为空。任何"已完成航班的平均延误"都会高估可靠性。
2. **延误原因字段不完整**：`CarrierDelay/WeatherDelay/NASDelay/...` 仅对**到达延误 ≥15 分钟且未取消/未改道**的航班填写（本数据中仅占 11.5%），且为承运人自报，**不是独立核实的根因**。
3. **取消原因代码**只有 A（承运人）/B（天气）/C（国家空域系统）/D（安全）四类粗分类。
4. **站点天气 ≠ 航班遭遇的天气**：METAR 是机场单点地面观测；航路对流、上游机场的地面停止不会体现在本场观测中。
5. **报告口径**：仅"报告承运人"在册（约占美国国内航班 95% 以上），不含全部通用航空与部分包机。
6. **2026 年仅到 9 月**，用于样本外检验时缺 Q4 与年末假期高峰，季节性截断必须说明。
7. **BTS 时刻为本地时间、IEM 为 UTC、LCD 为当地时间**，三者不可直接拼接（见 `数据字典.md` §9）。
8. **2026 年取消率异常偏高**（1 月 4.71%、3 月 2.90%）——应在建模时单独检查是否为真实事件（冬季风暴/系统性中断）而非数据问题，这恰是第 4 问"困难的日子"的天然素材。
